# tuiping｜公众号推品内容生成

这个项目只做一件事：**用户提供淘宝或天猫商品链接，Codex 获取对应商品详情和图片，直接生成可以用于微信公众号的推品标题、完整文案和贴图方案。**

用户不需要填写资料表、建立任务目录或整理商品参数。

## 怎么使用

直接发送商品链接，例如：

```text
https://item.taobao.com/item.htm?id=商品ID
https://detail.tmall.com/item.htm?id=商品ID
```

如果有指定颜色、尺寸、套餐、活动价或写作方向，可以和链接一起说明；没有额外要求时，Codex 按商品页面信息自动完成。

## Codex 会做什么

1. 打开链接并确认商品 ID、品牌、店铺和商品名称。
2. 获取页面中的规格、材质、尺寸、SKU、价格、优惠、卖点、适用场景和购买限制。
3. 获取可用的主图、SKU 图和详情图，并区分图片用途。
4. 核对重要信息，区分页面参数、商家宣传和用户反馈。
5. 直接生成公众号推品成品。

## 默认交付内容

每个商品默认输出：

1. 商品信息摘要和资料获取情况。
2. 商品核心卖点、局限、适合人群和不适合人群。
3. 10 个公众号标题及 1 个推荐标题。
4. 公众号摘要。
5. 可直接排版发布的完整正文。
6. 封面文案和封面图方案。
7. 正文贴图清单：使用哪张图、放在哪一段之后、配什么图注。
8. 可获取的商品原图和需要制作的成品图清单。
9. 商品卡或购买链接的建议插入位置。
10. 发布前需要确认的价格、SKU、活动和合规事项。

具体成品结构见 [输出示例](./OUTPUT_EXAMPLE.md)。

## 页面打不开时

淘宝或天猫页面如果要求登录、触发访问限制或隐藏部分详情，Codex 会先提取仍可获取的内容，然后只列出需要用户补充的具体截图，例如：

- 商品主页面全屏截图。
- 目标 SKU 和价格截图。
- 规格参数截图。
- 商品详情长图或需要使用的商品原图。

不会要求用户填写复杂模板，也不会使用相似商品资料代替当前商品。
