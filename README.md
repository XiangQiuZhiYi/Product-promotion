# tuiping｜省心实用生活清单

这是微信公众号带货项目，当前定位为：**面向上班族和小家庭的省心实用生活清单**。

项目内容以“替读者节省筛选时间”为核心，通过公开、可核验的商品资料，整理商品的适用场景、关键参数、购买注意点和不适用人群。

## 项目协作方式

1. 用户完成选品并提供商品链接或商品清单。
2. Codex 收集并核验公开商品信息。
3. Codex 整理选题、标题、公众号文案和配图方案。
4. 用户确认重要事实、活动信息和最终发布版本。
5. Codex 根据发布后的数据继续优化选题和表达。

## 项目规则

所有已经确认、后续持续补充的规则统一维护在 [PROJECT_RULES.md](./PROJECT_RULES.md)。开始新的选品、写稿或配图任务前，应先遵守该文件中的现行规则。

商品资料默认通过淘宝或天猫标准网页链接提供，具体处理流程见 [TAOBAO_WORKFLOW.md](./TAOBAO_WORKFLOW.md)。
